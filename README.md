# Ten-year Clinical Trajectories of Multimorbidity in Adults Aged 50 Years and Over

This repository contains the source code, data, and key results for the dissertation project analysing ten-year clinical trajectories of multimorbidity in adults aged 50 years and over.

## Repository Structure

```
├── code/           # Analysis notebooks (run in the order described below)
├── data/           # Patient data used in the analysis
├── main results/   # Selected key figures and tables referenced in the dissertation
└── README.md
```

## Data

The `data/` folder contains a single CSV file with patient information:

- `masterDataOptimal_v220230323015634.csv` — patient-level dataset used as input for all clustering and survival analyses.

Due to its file size (~300MB), the dataset is not stored directly in this repository. It can be downloaded from Google Drive:
[masterDataOptimal_v220230323015634.csv](https://drive.google.com/file/d/1diUKvdefLtzoQwvjmUI8T2xhZZ393vZ9/view?usp=sharing)

## Code and Running Order

The analysis is carried out in three main steps. Notebooks should be run in the order below, as later steps depend on the outputs of earlier ones.

### Step 1 — Clustering across three time periods

Performs MCA-based clustering of patients for each of the three study periods and generates heatmaps summarising cluster characteristics.

- `new_before12optimized_mca_clustering_cells.ipynb` — clustering for the **before-2012** period
- `new12_17optimized_mca_clustering_cells.ipynb` — clustering for the **2012–2017** period
- `new_after17optimized_mca_clustering_cells.ipynb` — clustering for the **2017–2022** period

**Outputs:** hyperparameter tuning summaries (`Before12_hyperparameter_tuning_summary.csv`, `12_17hyperparameter_tuning_summary.csv`, `17_22hyperparameter_tuning_summary.csv`) and `combined_heatmap.png`

### Step 2 — Cluster transitions (Sankey and bubble plots)

Visualises how patients transition between clusters across the three time periods.

- `color_named_Sankey_Bubble_clustering_cells.ipynb`

**Outputs:** `Sankey.png`, `transition_contribution_bubble_2012_2017.png`, `transition_contribution_bubble_2017_2022.png`

### Step 3 — Survival analysis

Compares Cox proportional hazards models against Random Survival Forest (RSF) models to assess mortality and disease progression across clusters.

- `8020cox_survival_vs_RSF_analysis_2012_cluster-2-3.ipynb` — RSF hyperparameter tuning, followed by the main Cox-based survival analysis (Kaplan–Meier curves, forest plots, etc.) used in the dissertation
- `cox_vs_RSF.ipynb` — comparison between the Cox model and the tuned RSF model

**Outputs:** `cox_model_comparison_impact_cindex.png`, `cox_top_hr_forest_plot.png`, `km_and_mortality_...png`, `multi_disease_survival_curves.png`, `multivariable_disease_distribution_and_hr.png`

## Main Results

The `main results/` folder contains a selected subset of key figures and tables generated by the notebooks above, corresponding to the results presented in the dissertation. Not all intermediate outputs are included; only those referenced in the final report are provided here.

## Environment / Requirements

All analyses were run using Python 3.13.9. 

Key packages and versions are listed in `requirements.txt`. Dimensionality reduction (MCA) used a fixed random seed of 42.
